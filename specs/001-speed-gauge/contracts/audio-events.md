# Contract: Audio and vibration

Two sound sets live in `src/Apps/AG-SpdGa/`:

- **App voice** (`voice/`, research R13): 512 Piper "Amy" files generated by
  `tools/voice/make_voice.py`, committed (FR-034, FR-035; CC BY-SA 4.0). The folder
  carries its own `CREDITS.txt` for Piper (MIT) and the Amy model
  (CC BY-SA 4.0) (FR-036).
- **Fallback** (folder root): DFM's five WAVs, copied unmodified from
  `docs/examples/dfm-speed-announce/DFM-SpdA/`, with `CREDITS.txt` naming DFM
  (Dave McQueeney) and the MIT license (FR-029, FR-037, constitution VIII).

`V` = `/Apps/AG-SpdGa/voice/`, `D` = `/Apps/AG-SpdGa/`. `unitFile` is
`V .. "mph.wav"` / `"kmh.wav"` / `"kt.wav"` / `"ms.wav"` / `"fts.wav"`.
"App voice" means `useAppVoice` and, for a phrase with a number, `n ≤ 500`
and `V .. n .. ".wav"` opens (research R14). Otherwise the fallback column
applies to the whole phrase.

| Event | Condition (data-model.md) | App voice | Fallback |
| --- | --- | --- | --- |
| Startup | `init()`, `startAnn = 1`, `cal ≠ 100` | `playFile(V.."cal.wav", Q)`, `playFile(V..cal..".wav", Q)`, `playFile(V.."pct.wav", Q)` | `playFile(D.."airspeed_cal_factor.wav", Q)`, `playNumber(cal, 0, "%")` |
| Startup | `init()`, `startAnn = 1` | `playFile(V.."stallat.wav", Q)`, `playFile(V..vStall..".wav", Q)`, `playFile(unitFile, Q)` | `playFile(D.."stall_speed_warning_at.wav", Q)`, `playNumber(vStall, 0, unitSpoken)` |
| Airspeed alive | first `armed` (speed above `vArm`) with a switch on | `playFile(V.."alive.wav", I)` | `playFile(D.."airspeed_alive.wav", I)` |
| Stall | stall armed → fired | `playFile(V.."stall.wav", I)`, `vibration(true, 4)` | `playFile(D.."stall_warning.wav", I)`, `vibration(true, 4)` |
| Overspeed | overspeed armed → fired | `playFile(V.."over.wav", I)`, `vibration(true, 3)` | `playFile(D.."overspeed.wav", I)`, `vibration(true, 3)` |
| Callout, full | callout due, not short form | `playFile(V..n..".wav", Q)`, `playFile(unitFile, Q)` | `playNumber(n, 0, unitSpoken, "Speed")` |
| Callout, short | callout due, short form | `playFile(V..n..".wav", Q)` | `playNumber(n, 0)` |
| Max speed | session max unchanged for 1 s and ≥ last announced max + sensitivity (FR-019a) | `playFile(V.."max.wav", Q)`, `playFile(V..n..".wav", Q)`, `playFile(unitFile, Q)` | `playNumber(n, 0, unitSpoken)` |

No callout or max callout below 5 mph or its equivalent (FR-008b).

`Q` = `AUDIO_QUEUE`, `I` = `AUDIO_IMMEDIATE`, `n = round(shownSpd)`.

- Warning paths for both sets are constants chosen once in `init()` from
  `useAppVoice`, and again when the Voice setting changes. `voiceOk`
  guarantees the app-voice warning files exist, so a warning is never silent
  (FR-033, SC-010).
- `unitSpoken` uses v2.1's strings, which match the voice pack's
  `numbers.jsn`: `mph`, `km/h`, `kt.`, `m/s`, `ft./s`.
- Callouts are skipped while `system.isPlayback()` is true (FR-007). The
  number and unit files are queued in the same tick, so FR-007 treats them as
  one phrase (FR-031). Warnings use `AUDIO_IMMEDIATE` and are not delayed,
  as in v2.1.
- Startup announcements in the app voice play the startup number through
  the same file check as callouts; `vStall > 500` or a missing file falls
  back for that announcement only.
- The number-path concatenation and `io.open` check happen only when a
  callout or startup announcement is due, never per loop (research R14).
- Vibration profiles 3 and 4 are v2.1's. The API doc names them "two short"
  and "three short"; v2.1's comments say 2 and 4 pulses. Keep the profile
  numbers; don't rely on either description.
- **UNVERIFIED** (research R13, R14): that the transmitter plays 22.05 kHz
  mono WAV; the pause between two queued files (SC-009, < 0.15 s); whether
  `AUDIO_IMMEDIATE` cuts a queued callout.
