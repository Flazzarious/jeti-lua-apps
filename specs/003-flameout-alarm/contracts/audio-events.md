# Contract: Audio and vibration

All sounds are in `src/Apps/AG-FlmOt/`, generated by
`tools/voice/make_flameout.py` and committed under CC BY-SA 4.0 with the
folder's `CREDITS.txt` (spec FR-026–FR-028, research R5). `A` =
`/Apps/AG-FlmOt/`. `I` = `AUDIO_IMMEDIATE`, `Q` = `AUDIO_QUEUE`.

| File | Content | Length |
| --- | --- | --- |
| `cycle.wav` | urgent "Flameout!" ×3, then lock tone | 5.000 s exactly |
| `cycletl.wav` | urgent "Flameout!" ×3, "Engine telemetry lost", lock tone | 5.000 s exactly |
| `tlost.wav` | "Engine telemetry lost" | ≈ 1.3 s |
| `armed.wav` | "Flameout alarm armed" | ≈ 1.3 s |
| `relit.wav` | "Engine relit" | ≈ 1 s |

Mono, 16-bit, 22.05 kHz, peak −1 dBFS.

## Events

| Event | Trigger (data-model.md) | Files present | Cycle files missing (R6) |
| --- | --- | --- | --- |
| Alarm start | ARMED → FLAMEOUT | `playFile(A.."cycle.wav", I)`; `vibration(false, 4)`, `vibration(true, 4)` | `playBeep(9, 1800, 120)` now and 2.5 s later; vibration |
| Alarm cycle | FLAMEOUT, 5 s after the previous cycle start | as alarm start, or `cycletl.wav` once if `tlPending` | as above |
| Alarm stop: relight | FLAMEOUT → ARMED | `stopPlayback(AUDIO_IMMEDIATE)`; then `playFile(A.."relit.wav", Q)` if `sayRel` | `stopPlayback(AUDIO_IMMEDIATE)` |
| Alarm stop: Cut | any → DISARMED by Cut while FLAMEOUT | `stopPlayback(AUDIO_IMMEDIATE)` | same |
| Alarm stop: monitoring off | settings change sets `active` false while FLAMEOUT | `stopPlayback(AUDIO_IMMEDIATE)` | same |
| Telemetry lost | ARMED, invalid for `lossMs` | `playFile(A.."tlost.wav", I)` | skipped (screen shows NO TELEMETRY) |
| Telemetry lost | FLAMEOUT, invalid for `lossMs` | next cycle plays `cycletl.wav` (R4) | beeps continue |
| Armed | DISARMED → ARMED, `sayArm = 1` | `playFile(A.."armed.wav", Q)` | skipped |
| Test start | test switch off → on, state OFF or DISARMED (R13) | as alarm start (`cycle.wav`) | as alarm start |
| Test cycle | test on, 5 s after the previous cycle start | as alarm cycle (`cycle.wav` only) | as alarm cycle |
| Test stop | test switch off, or the app arms | `stopPlayback(AUDIO_IMMEDIATE)` | same |

Rules:

- **Nothing sounds while OFF or DISARMED** (FR-012, SC-009) except a test
  alarm the pilot starts with the test switch (FR-030a).
- Cycle start times are `cycleAt + 5000·k`, checked on the 100 ms tick
  (SC-012: ±0.3 s). If the app fell more than one cycle behind (it never
  should), it restarts the rhythm from `now`.
- **Pre-emption** (FR-025): `AUDIO_IMMEDIATE` stops any foreground playback,
  including other apps' speech. Another app's `AUDIO_IMMEDIATE` (e.g. Speed
  Gauge's stall warning) or a transmitter alarm can cut a cycle short; the
  alarm resumes at the next 5-second boundary (R3).
- File existence is checked once in `init()` (five `io.open` calls), never
  in `loop()`.
- The confirmations use `AUDIO_QUEUE` so they never cut another app's
  callout; the alarm and "telemetry lost" use `AUDIO_IMMEDIATE`.
- **Unverified until transmitter testing:** the gap between `playBeep`
  repeats; that `stopPlayback(AUDIO_IMMEDIATE)` silences mid-file with no
  tail; the firmware's own telemetry "valid" timeout (R9).
